# カンペき キャラクター素材 v1

元アイコンを参照し、ImageGenで口閉じ・口開き・弾む姿を制作。今回の成果は素材と動作見本。アプリ画面への組込み、TestFlightへの反映は未実施。

## 素材

- `sheet.png`：1774×887px、4列×2行の元画像。
- `frames/`：443×443pxの8コマ。口閉じ、口小、口開き、口小戻り、待機、沈み込み、ジャンプ、着地。
- `talk.gif` / `talk.apng`：約1.68秒の口パク。GIFは閲覧用、APNGはフルカラーの動作見本。
- `bounce.gif` / `bounce.apng`：約2.24秒のジャンプと着地。
- `*.ffconcat`：再生順と各コマの時間。

イラストの生成・輪郭修正はImageGen。ffmpegでコマを矩形分割し、時間順にアニメーションへ梱包した。コマの切出しは左上から443pxごと、右端2pxと下端1pxの余白を除外する。元アイコンは別の正式原本であり、このシートで置き換えない。

背景あり（淡いグリーン）の素材。透過版の試作は輪郭の白いノイズがあったため採用していない。背景がわずかに揺らぐ可能性があるため、まず同じ背景の角丸キャラクター枠内で使う。自由な位置へ透過キャラクターとして重ねる用途には、そのまま使わない。ImageGen由来の微小な輪郭差がある。

## 動きの使い分け

| 場面 | 動きの案 | 制限 |
|---|---|---|
| 案内の一言 | 口閉じ→小→開き→小→閉じ | 1〜2回、説明終了で止まる。音声同期は未実装 |
| 接続・準備の完了 | 沈む→跳ねる→着地 | 成功時に1回。次の操作を止めない |
| 次の入力場所へ案内 | キャラクター枠を300ms程度で移動、終点で小さく弾む | 実装側の位置・scaleアニメーションで行う。GIF内には横移動を含めない |
| 処理待ち | 口閉じの静止画、必要なら弱い呼吸 | 常時のジャンプや点滅は使わない |
| 発表中 | 原則静止・小さく表示、必要なら非表示 | 下部スライド、原稿、ポインターを遮らない |
| 結果画面 | 一度だけ喜ぶ | 感情や点数を架空に判定した演出はしない |

通常表示の提案はiPhone64〜88pt、Mac80〜112pt。これはコマ全体のサイズで、キャラクター本体には余白がある。アニメーションに合わせてレイアウトを伸縮させず、枠の中だけを変化させる。画面から外れたら停止する。
Reduce Motion時は口閉じの静止画にし、画面間の移動・弾みを省略する。装飾画像はアクセシビリティの読み上げ対象から除外し、案内文は別のテキストで提供する。

素材のGIFは動きを比較するためループする。本番ではイベントごとに短く再生し、常時ループにしない。最小限の操作という既存方針を維持する。
