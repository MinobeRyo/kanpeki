# 移植前の初版の検証記録

2026-09-15。テスト対象はこのリポジトリの音声モジュール。

## 自動テスト

`PYTHONPATH=backend python3 -m unittest discover -s backend/tests -v`

18件成功。

- 既知の音/ゼロ信号を合成したWAVによる、低音量区間の開始・終了・最小長。
- 不正形式、サンプルレート違い、ステレオ、切れたWAV、短すぎる録音を拒否。
- モデル未導入/実行失敗/発話未認識を未計測として返す。
- 文の範囲に基づく話速とフィラー候補、ページ戻りを含むスライド時間。
- 実際のループバックHTTPによる認証、送信、結果取得、再送の重複排除、不正データ、削除、保持期限。

フィラー候補の単体テストでは既知の文字起こしを注入しており、音声認識精度の検証とは区別する。

## 実モデル・通信のスモークテスト

- macOSの日本語合成音声（Kyoko）を明示的にファイル出力し、16kHz mono PCM16 WAVへ変換。
- 長さ17.712秒。途中に1.8秒の間を含めた検証用原稿。
- whisper.cpp 1.9.4 + 多言語baseモデルでローカル文字起こしが完了。
- アプリと同じ `AudioAPI.swift` をMacでコンパイルし、実HTTPの送信→分析→JSON読み取りを確認。
- 同一音声を2回送っても結果が重複しないこと、スライド時間、結果のnullable項目も確認。
- モデルなしの経路はPythonの実HTTPテストで確認。

実行方法（WAVは自分で指定する）:

```sh
python3 scripts/contract_smoke.py /path/to/test.wav \
  --whisper-cli "$(command -v whisper-cli)" \
  --model .tools/models/ggml-base.bin
```

検証用原稿の「えー」は文字起こしから欠落した。「実験」に誤認識も見られた。
これは動作経路の確認であり、日本語フィラーの検出精度を保証する評価ではない。
生音声・モデル・検証用の原稿結果はGitに含めていない。
