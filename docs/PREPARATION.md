# 事前準備の範囲

提供された「OpenAI 大学生向け 夏の Codex 開発祭 2026」資料33ページを根拠とする。企画のMarkdown化、不確定要素の整理、画像によるモック、必要環境の準備、GitHubリポジトリの基本設定・ワークフロー作成は準備例として記載されている。最終プロダクトのプロトタイプへの着手は避ける。

このリポジトリでは、設計資料・基本ルール・空の仕様書テンプレート・準備用ワークフローまでを対象とする。大会の追加指示があれば確認して反映する。

事前に含めないもの: 既存の製品コード、動作するモック、既存テスト、バイナリ、旧git履歴、作業記録、旧ファイル一覧、個人情報、認証情報。

本番開始は人間の明示的な指示を受ける。事前準備から本番へ切り替える際に、各機能の仕様書、最小実装範囲、担当、テスト計画を確認する。
