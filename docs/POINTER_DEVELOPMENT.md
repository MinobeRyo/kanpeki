# ポインター実装と確認（Issue #16）

既存のiPhone下部スライドと左右タップを維持し、移動中だけMacへレーザーポインターを表示する。長押しは要求しない。UIKitの全タッチを確認し、2本目の指・余白への移動・画面離脱・通信状態の失効でその操作全体を取り消す。ドラッグ後に開始位置へ戻して離してもページ送りしない。

## 入力と通信

- 表示画像のaspect-fit領域から0〜1の絶対位置へ変換する。相対差分の積算を使わず、パケット欠落後も次の位置で復帰する。
- 移動閾値は暫定8pt、タップは0.5秒未満。実機で片手操作・手ぶれの評価を行うまでは確定値としない。
- 移動送信は最大30Hz、MultipeerConnectivityのunreliable経路。指離し/取消はreliableなclear。再送キューを独自に作らない。
- `state.pointerSessionID`、`kind=pointer`、`pointer={sessionID,sequence,point}`を任意追加。`point=null`は終了。Macは古いsession、逆順/重複sequence、範囲外・非有限座標を捨てる。接続変更、同期停止、ページ/資料変更でsessionを更新する。
- 状態と画像が3秒以上古いと操作を禁止する。Macは移動が250ms届かなければ非表示にするので、clearパケットを受信できない場合も表示が残らない。

## Mac表示

共有対象ウィンドウの現在座標にクリック透過・非アクティブ化NSPanelを重ねる。OSカーソルの移動やクリックを合成せず、追加のアクセシビリティ許可を要求しない。PowerPoint同期・共有が有効で、共有対象アプリが最前面の間だけ表示する。デスクトップ座標は画面上端基準からAppKitへ変換する。

キャプチャ対象は既存方式のウィンドウ全体であり、スライドショーのコンテンツだけを選ぶ必要がある。PowerPoint内部の黒帯や発表者ツール画面を自動識別する機能ではない。iPhone側のaspect-fit余白は除外するが、画像内に焼き込まれた黒帯は自動除外しない。Mac側ポインターは別ウィンドウなので元のキャプチャ画像には含めない。

## 検証

`bash scripts/check.sh core`で正規化、レターボックス、左右タップ、移動後指離し、30Hz上限、複数指、領域外、失効、順序逆転、古いsession、通信契約を検証する。`mac`と`phone`で双方を署名なしビルドする。

未実施：実iPhoneとMac間の追従/タップ30回、PowerPoint全画面/外部ディスプレイ/Spaces/ウィンドウ移動/重なり/画面収録許可、パケット損失、片手閾値調整、TestFlight実機検証。Windowsは現行ネイティブ製品の対象外で、表示方式/権限を検証していない。QR/WebSocketへの移行は #19 に残す。Issue #16 全体の完了とは扱わない。
