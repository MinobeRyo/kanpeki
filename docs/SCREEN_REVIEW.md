# アプリ内の画面構成チェック

Issue #10 のUI確認用。ImageGenの採用案（`assets/design/device-size`、`assets/design/assistance`）を参照し、接続→準備→発表→固定→結果をネイティブ画面で試せるようにした。生成画像を実機の動作結果とは扱わない。

## 開き方

更新されたアプリのホームで「画面構成を試す」を選ぶ。iPhone接続中は右上の詳細メニューから開く。Macは上部の同名ボタンから開く。上部タブでも5画面を移動でき、閉じると実際の接続画面へ戻る。

SlackのTestFlightリンクはインストール先であり、最新UIを含むビルドが配布されるまでは旧画面が開く。配布通知のバージョンとTestFlightのビルドを照合する。マージ通知だけでは更新完了を意味しない。配布はIssue #28で管理する。

## 確認すること

1. 接続：キャラクターの案内、Mac選択の配置。「デモのMacで続ける」で準備へ。
2. 準備：資料・時間・翻訳と原稿チェック。案内は閉じても作業を続けられる。
3. 発表：下部スライドの右タップで進み、左タップで戻る（全3枚）。ドラッグではローカルのポインターが動き、指を離してもページを送らない。「終了して結果へ」で結果に移る。
4. 固定：カメラ設置案内と映像領域の配置。実際の撮影はホームのカメラ設定から別途確認する。
5. 結果：話し方／カメラの切り替えと、準備へ戻る流れ。小さな画面ではスクロールして内容を確認する。
