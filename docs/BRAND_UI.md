# アイコンと画面調整（Issue #24）

ユーザー提供の正式ロゴを、iPhoneの1024pxアイコンとMacの各サイズのアイコンに反映。Mac用はsipsで必要寸法に縮小し、原本の意匠は変更していない。画面内でもBrandMascotとして使用する。

背景は淡い緑、内容面はアイボリー、文字と操作はスレート。現段階は明るい配色に固定する。暗い配色は別途検証する。元資料の色は変更しない。

iPhoneは原稿を上部のスクロール領域、スライドを下部に配置。右の短いタップで進み、左で戻る。8ptを超える移動と0.5秒以上の接触ではページを送らない（実機で調整する仮値）。ドラッグ後の指離しでページを送らない。ポインター送信は未実装で、今回追加したものではない。VoiceOverには前／次のカスタム操作を用意した。

接続状態と原稿の詳細、未実装機能の説明はメニュー内に整理。未接続時はMac検索と接続先の選択を案内する。QR接続は実装していないので画面へ置かない。Mac側もキャラクターと配色を揃え、試作用の技術ラベルを減らした。

検証：Mac DebugとiPhone Simulator Debugの署名なしビルド成功、Swiftコア17チェックとworktree管理3テスト成功。実機の可読性・ジェスチャー・アクセシビリティ操作は未確認。TestFlight配布には新しいビルドが必要。審査中ビルドには反映されない。
