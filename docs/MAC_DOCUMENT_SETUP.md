# Macで資料を開いて発表する

Issue #77。#61の安全な開始・取消・共有復旧を引き継ぎ、資料プレビューと準備導線をつなぎます。

## ホームと戻る

起動時は「発表準備」「iPhone接続」「分析・結果」の3つを表示します。接続/分析はPPTXや画面共有なしで開けます。各画面の「戻る」は直前の画面へ戻り、資料・設定時間・録音受信・結果を破棄しません。開始処理中に発表画面を離れた場合だけ、その開始を取り消します。

「iPhone接続」のQRはスライド/リモコン用です。音声送信用URL/コードは同画面の「音声送信・接続の設定」または「分析・結果」→「音声分析」から表示します。モデル準備後に受信を開始すると表示されます。2つの接続は現時点では別経路です。

## 操作

1. ホームの「発表準備」→「PPTXを選ぶ」で資料を選択します。表紙を表示し、「準備・機能」→「資料を大きく見る」で全ページを確認できます。原稿も同じPPTXから読み込みます。
2. 「PowerPointで開く」で選択したファイルを開きます。カンペきの案内を保持して資料を開きます。PowerPointのウィンドウでスライドショーを開始し、カンペきに戻ってください。
3. カンペきの「共有画面を選ぶ」で、観客向けのスライド画面を選び、確認して適用します。発表者ビューを選ぶと原稿も共有されるため、対象を確認してください。
4. iPhoneを使うか、Macだけで練習するかを選びます。
5. 発表時間を分・秒で設定して確認します。
6. 「発表を始める」。共有画像とPowerPointの現在ページを確認できてからタイマーが始まります。

準備中は未完了の一段だけを表示します。変更はMacメニューバーの「ファイル」「準備」からできます。発表中の一時停止・終了はメニューバー「発表」にあります。補助機能はホームの「分析・結果」から開けます。音声分析と「ChatGPTで振り返る」はメニューバー「準備」からも開けます。振り返り画面の「共有の設定」で明示的に共有を開始/停止します。

## 表示と制限

- Quick Lookは保存済み資料のプレビューで、PowerPointの現在の発表ページとは別です。未保存編集やアニメーションをライブ表示したとは扱いません。
- 発表中はQuick Lookを表示せず、既存のPowerPoint画面取得とslide ID/pathの照合を使います。画像が止まったら更新待ちとして共有復旧へ案内します。
- 主画面は戻る＋主操作＋準備メニューの3つ以内。全ページプレビューはページ送り2つ＋戻る1つ。発表中は送り戻り2つ＋画面の戻る1つ。OSのタイトルバーやファイル選択パネルはMac標準です。
- 資料選択の取消・読込失敗では前の資料を保持します。読込中に発表セッションが変わった場合は結果を適用しません。新しい資料の読込成功時に以前の共有対象を解除します。
- PowerPointが未導入、ファイルが移動/削除された場合は短い案内を表示します。アプリ起動だけでPowerPointや画面収録権限を要求しません。
- 画面収録・PowerPoint操作の権限は、共有/開始を実行するときに必要です。PPTXの内容確認には画面収録は不要です。

## 検証

準備分岐の回帰チェック、既存coreと開始/取消/共有復旧チェック、Mac/iPhoneビルドを実施します。実UIでの資料選択、Quick Lookの複数ページ、PowerPointで同一資料を開くことを確認しました。実機共有・権限・配布の結果はIssueに記録し、ビルド成功だけで検証済みと扱いません。
