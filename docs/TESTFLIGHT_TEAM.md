# チームで最新版を開く

1. 受信した **TestFlightの招待メール**から参加する。iPhone版とMac版はそれぞれ招待が必要。App Store Connectへのログインだけでは参加は完了しません。
2. [TestFlightを入手](https://testflight.apple.com/)し、対象端末のTestFlightで「カンペき」を開いて「更新」。
3. バージョン欄のビルド番号を、Slackの最新配布通知と照合する。通知の「内部テスト可能」は配布側の状態で、各自のインストール完了を意味しません。

以前のSlackにある公開招待リンクは外部テスト用です。内部テストより古いビルドが表示されることがあります。チームの最新版確認には上の招待メールを使ってください。

## 更新が出ない場合

- メールがApp Store Connectのユーザー招待か、TestFlightのアプリ招待かを確認。ユーザー招待のみの場合はTestFlightの招待を管理者へ依頼。
- 対象アプリの新しいTestFlight招待を開き直す。参加に使ったApple Accountも確認。
- まだ更新が出ない場合は、TestFlightのアプリ名・バージョン・ビルド番号が見える画面を管理者へ共有。招待コードや個別招待URLは共有しない。
- 記録データを守るため、更新確認だけを目的にアプリを削除しない。

## 管理者・配布担当

GitHub Actionsの成功だけで完了扱いにしない。対象ビルドの処理完了・期限・内部グループへの割当・内部配布状態をApp Store Connectでも確認する。テスターの参加状態と端末インストールは別に確認する。
外部テスト用URLを内部配布のボタンに転用しない。個人の招待URLやメールアドレスをリポジトリへ記載しない。
