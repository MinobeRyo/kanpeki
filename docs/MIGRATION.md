# プロダクト移植の記録

2026-09-15、ユーザーが「プロダクト本体も移してよい」「Slackとの連絡機能も入れる」と許可したため、資料のみの移植から範囲を変更した。

## 出所

移植元：takurateruyoshi/kanpeki のmain、コミット `1436989be954a50031f0462510b7c0e2934dbcc7`。
旧git履歴を結合せず、追跡済みファイルのスナップショットを取り込んだ。既存プロダクトの持ち込みであり、大会中に全コードを新規開発したものとは説明しない。会場写真は提出物のヒントで、持ち込み規約全文ではない。

## 移したもの

Mac／iPhone／Shared、Xcodeプロジェクトと設定、コア・運用テスト、配布用スクリプトとFastlane、Slack通知、worktree管理、共有skills、再移植用テンプレート、SlidePacer実験コード、仕様・画像。
旧アプリの実装はPowerPoint表示の取得、PPTXノート読み込み、MacとiPhoneの通信を含む。最新の少ない操作・下部スライド配置・キャラクター案内・翻訳／分析結果の画面案と完全に一致するものではない。SlidePacerは別の実験アプリで、Mac/iPhone本体への統合済み機能ではない。

## 新リポジトリ向けの修正

- チーム・通知・マージ確認・再移植ツールの参照先をMinobeRyo/kanpekiへ更新。
- マージ通知と変更内容のスレッド返信を追加。Issue進捗通知と配布通知も取り込み。
- SlackのSecretと変数はrepository単位。Appleのtestflight環境に依存させない。
- 通知文章は短く、PR本文は実行しない。pull_request_targetはマージ済みイベントだけを受け、mainのコードを使用する。
- 安価なUbuntuの運用テストを追加。ネイティブCIは対象パスと明示フラグで制御する。
- 旧リポジトリの必須CI名が存在すると仮定してマージを拒否する処理を修正。最新ルールを取得できなければ停止する。

## CI/CDの有効化状態

Slack通知コードとアプリ本体の移植は、TestFlight再配布の完了を意味しない。
`NATIVE_CI_ENABLED`、`IOS_TESTFLIGHT_ENABLED`、`MAC_TESTFLIGHT_ENABLED`、`MAC_DISTRIBUTION_ENABLED`は未設定ではネイティブジョブ／配布を起動しない。まずXcode・署名・配布先・費用を確認する。現構成は旧方式を保持しており、複数の配布フラグを同時に有効にすると共通CIが重複する可能性がある。全配布を自動有効化する前に同一コミットの検証を一本化する。
署名用Secretsは移植していない。Bundle IDなど既存アプリの識別子は維持したが、旧リポジトリと同じAppleアプリへ並行アップロードするとビルド番号が競合し得る。新しい採番を確定するまでは配布を開始しない。
