## 開始処理の安全条件

- 1回の開始意図にUUID・画面ID・資料パス・タイマーsession/revisionを固定。二重押下を無効化し、取消または対象変更後の完了を拒否する。
- iPhoneを使う開始は接続世代も固定し、準備のawait中に切断／接続変更があれば取り消す。Macだけで始めるを明示的に適用した場合だけ、この依存を外す。
- 共有失敗、PowerPoint同期失敗、画像取得失敗／期限切れ／復号不可で時計を開始しない。画像取得は既存のソースページ同一性検証を維持する。
- 初回権限は「許可して探す」または更新ボタンからだけ要求。起動・パネル再表示・取込後の自動更新は既存の許可を確認してから列挙する。
- 終了確認はsession IDを保持し、別セッションを終了しない。タイマー終了中は再開始不可。
- 発表中の共有停止やPowerPoint同期失敗は、パネルの「共有・操作を確認し直す」から画面選択→確認→再共有できる。復旧モードは同じ開始ガードを再利用するが、時計のstart/resetを行わず、経過時間・一時停止・sessionを維持する。確認時と実行時のsession/revision/接続を照合し、古い確認を別発表へ適用しない。
- 共有開始／停止の非同期処理中もタイマーとMCP共有世代・既存分析結果を保持し、一時的な空の状態を流さない。MCP共有の停止や発表変更による正規の無効化は既存処理に従う。
- 矢印キーは該当ウィンドウだけ。NSTextView/NSTextField編集中やシート表示時はイベントを消費しない。
