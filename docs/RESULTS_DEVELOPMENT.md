# 結果画面の実装範囲

Issue #13、ASSISTANCE_FLOW R01〜R05のうち、取得済みカメラ結果を既存のカメラ補助パネルへ表示する。Mac/iPhone本体の配置・手動スライド操作は変更しない。

- カメラ対象、取得できた秒数、うなずき候補のあった秒数、未計測秒数を表示。動作回数・感情・理解率ではない。
- 分析OFF、準備中、確定待ち、開始前取消、権限不足、入力断・中断、解析失敗を区別する。可能な途中結果は保持する。
- 開始ごとにUUIDで結果を区別し、以前の非同期結果で新しい結果を上書きしない。
- 結果の確定中も準備へ戻れる。結果削除は確認ダイアログ後のみ。表示したセッションIDと一致しない場合、または計測・確定中は削除しない。
- 保存は撮影端末のメモリのみ。次のカメラ開始・アプリ終了・明示削除で破棄する。録音や映像保存、外部送信は追加しない。

## 撮影開始からの時間帯（R03の部分実装）

既存CameraPanelの個別結果に、展開式の時間帯別テキストを表示する。撮影開始からの相対時間だけを使い、発表・音声の時間軸とは同期しない。取得できた秒数、未計測秒数、観客のうなずき候補秒数を示し、全て未計測の区間は候補を評価できないと表示する。

初期幅は10秒、最大120区間。長時間では隣接区間を倍の幅にまとめ、合計を保持する。空白は未計測として保持し、巨大な時刻差でも秒単位の配列作成や反復はしない。秒境界は既存解析エンジンの20ms許容に合わせた概算で、未完了の端数秒は含まない。原画像・顔情報・絶対時刻は保持せず、結果削除・新規撮影で一緒に破棄する。

発表結果向けの集計差分には時間帯を付けない。発表開始位置で正しく切り出す処理がないため、撮影全体の時間帯を発表中の結果として再利用しない。統一時系列グラフ、発表・音声との同期、端末間結果同期は未実装。

## 発表の終了サマリー

Macの準備パネルとiPhoneの「…」→発表時間に、タイマー終了後だけ「発表の結果」を表示する。実測時間はMacが確定したtimer.elapsedSecondsを使用し、カメラ秒数やサンプル表示から作らない。一時停止した時間は発表時間に含まない。

カメラとの関連付けは端末内だけで次の条件を満たす場合に限る。

- 同じtimer.sessionIDのready→runningを観測した時、その時点で準備中・計測中のカメラを関連付ける。開始を端末が観測した時点の集計を差し引き、準備中のカメラ集計は結果へ含めない。通信・UI更新の遅延があるため、物理的な発表開始時刻と完全一致する切り分けとは扱わない。
- 発表中・一時停止中に新しく開始されたカメラは、その発表へ関連付ける。再撮影した場合は最後の撮影だけを表示し、複数撮影を合算したと見せない。
- 発表中に新しいcamera UUIDが初めて現れた場合は、UI更新がまとめられて準備中を観測できず、直接権限不足・失敗・取消となっていてもその試行を関連付ける。新規撮影のbaselineはゼロとし、以前の集計を差し引かない。初回の途中接続snapshotではこの処理を行わない。
- 途中接続の最初のrunning/paused/endedでは既存カメラを関連付けない。前のcompleted/failedを新発表へ付け直さない。切断・新timerセッションでは関連付けを消す。
- 終了直後のfinalizing→completedは固定したcamera UUIDのみ追随する。削除・別の撮影開始後は以前の結果を復元しない。結果削除は既存同様、確認後に表示したcamera UUIDを指定して行う。

カメラは当端末の結果と明示。カメラの一時停止連動はないため、発表タイマーの実測時間とカメラ計測の秒数は異なる場合がある。既存CameraPanelの個別結果は撮影全体の集計を保ち、発表結果パネルだけが準備期間を差し引く。画面確認モードのサンプルとは接続しない。

共通終了サマリーの音声詳細は未接続。別のiPhone音声画面では同発表の録音分析結果・フィラー候補と保持音声の聞き直しを利用できる（[AUDIO_CAPTURE](AUDIO_CAPTURE.md)、[FILLER_CHAPTERS](../specs/FILLER_CHAPTERS.md)）。共通サマリーの改善候補・統一時系列は未実装。Issue #13全体は実機受け入れと残件があるため未完了として残す。

検証は `swift test`、`npm test`、`bash scripts/check.sh core`、`bash scripts/check.sh mac`、`bash scripts/check.sh phone`。実機カメラ権限・バックグラウンド中断・SwiftUI削除操作の実機検証は別途必要。
