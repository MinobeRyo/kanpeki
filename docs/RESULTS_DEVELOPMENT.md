# 結果画面の実装範囲

Issue #13、ASSISTANCE_FLOW R01〜R05のうち、取得済みカメラ結果を既存のカメラ補助パネルへ表示する。Mac/iPhone本体の配置・手動スライド操作は変更しない。

- カメラ対象、取得できた秒数、うなずき候補のあった秒数、未計測秒数を表示。動作回数・感情・理解率ではない。
- 分析OFF、準備中、確定待ち、開始前取消、権限不足、入力断・中断、解析失敗を区別する。可能な途中結果は保持する。
- 開始ごとにUUIDで結果を区別し、以前の非同期結果で新しい結果を上書きしない。
- 結果の確定中も準備へ戻れる。結果削除は確認ダイアログ後のみ。表示したセッションIDと一致しない場合、または計測・確定中は削除しない。
- 保存は撮影端末のメモリのみ。次のカメラ開始・アプリ終了・明示削除で破棄する。録音や映像保存、外部送信は追加しない。

音声分析は未接続と表示し、フィラー・間・改善候補や再生ボタンを作らない。発表タイマーの経過時間、終了時の統合サマリー、時間帯別グラフ、端末間結果同期は未接続。カメラ計測の秒数を発表時間に見せない。Issue #13全体は未完了として残す。

検証は `swift test`、`npm test`、`bash scripts/check.sh core`、`bash scripts/check.sh mac`、`bash scripts/check.sh phone`。実機カメラ権限・バックグラウンド中断・SwiftUI削除操作の実機検証は別途必要。
