# SlidePacerの取り込みとMCPへの移行

既存の資料読み込み・原文ID復元・時間配分・結果表示を `apps/SlidePacer` に取り込み、`Kanpeki.xcworkspace` に登録しました。分析経路はChatGPTのMCP接続へ変更しています。

現在の起動方法、データの流れ、検証範囲と残件は [MCP_INTEGRATION](MCP_INTEGRATION.md) を参照してください。Issue #33 が統合、#56 が並行精度評価の記録です。

## 引き継いだもの

- PPTX/JSON/手入力からの本文・発表者ノート取り込み
- 原文IDによる説明内容の復元と、Swiftによる決定的な時間配分
- 入力検証、取消、結果のJSON保存、既存回帰テスト
- 署名Teamを固定しない独立したSlidePacerターゲット

旧Git履歴、モデル本体、個人資料、評価の生データ、キー、個人のXcode設定は含めません。既存Ollama補助コードは回帰比較用に残りますが、アプリの分析操作からは呼ばれません。

## 検証記録の扱い

移行前のローカルLLMの評価はMCP版の精度や配布成功として扱いません。実資料に由来する詳細な評価内容は非公開のローカル記録として保管します。統合の接続成否とコードの回帰検証は #33、並行評価の作業状態は #56 で管理します。
