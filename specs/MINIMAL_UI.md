# 少ない操作の画面

- iPhone接続: キャラクターと「Macにつなぐ」を中央に配置。Mac候補は一つの選択メニューにまとめる。検索し直す操作は候補がある場合メニュー内に置く。音声・画面見本は補助メニューから開く。
- メニュー: 発表／その他／閉じるの3入口。発表画面の時間操作は最大2つ＋戻る。
- 時間: 整数の分・秒で入力。初期値5分、既存270秒は4分30秒。1分〜24時間の制限とセッション変更時の適用拒否を維持。入力はキャンセル／次へ、確認はキャンセル／戻る／適用。
- 画面見本: 5つの常設タブはメニューへ統合。準備画面はメニュー／時間調整／発表へ。サンプル注記は残す。
- 補助説明は短くし、操作ボタンと同じ内容の説明を繰り返さない。

接続の実処理とQR対応は#65、Mac準備画面は#61と調整する。カメラ・音声の詳細画面もこの基準に段階的に揃える。
