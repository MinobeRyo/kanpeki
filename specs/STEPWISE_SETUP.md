# 必要なときだけ、一問ずつ

ユーザー合意：回答が必要な機能は、選択後にステップごとに確認できるようにする。

## 時間を調整（今回の実装）

1. 通常画面：現在の時間と「時間を調整」の入口。常設の入力欄を廃止。
2. 入力：「発表は何分ですか？」。現在値、3/5/10分の候補、自由入力。
3. 確認：設定時間と「時間切れを通知、スライドは手動」の一文。戻る／適用。
4. 適用時のみ既存のconfigureコマンドを送信。表示値はMacから受け取った状態を正本にする。送信だけで成功と表示しない。
5. キャンセル・スワイプ終了は下書きを破棄。再入場時は現在値から開始。

空欄、非数、1〜1440分の範囲外は次へ進めない。接続切れ・情報期限切れ・発表開始・セッション/設定リビジョン変更では適用を止め、再入場を促す。時間の計測・通知・通信契約は既存仕様を維持する。

## 他機能への共通ルール

- 一画面一問。確定ボタンは最後に一つ。説明はその段階に必要な内容だけ。
- 翻訳・原稿チェックなど未統合の機能は入力を要求しない。設定例の数値を本番結果に見せない。
- スライド別時間配分の自動計算は今回未実装。#34での統合時は全体時間→重点スライド→配分案の確認、という段階化を候補として検討する。これは未合意の詳細仕様である。
- 手動スライド操作・ポインターを妨げない。

## 確認手順

Mac/iPhoneの「画面構成を試す」→準備→時間を調整。入力、戻る、キャンセル、適用を試す。見本では実タイマーへ送信しない。
実機では実タイマーパネルでも同じ導線を確認し、片側の操作による設定変更・切断・発表開始時に古い下書きを適用できないことを確認する。
